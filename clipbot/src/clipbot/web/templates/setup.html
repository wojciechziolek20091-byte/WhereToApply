Welcome to clip mob

clip mob turns long YouTube videos into short TikTok clips with captions, and can post them for you.

Setup takes about 10 minutes. You will need:

Connect the AI

A free AI reads each video's transcript and picks the moments worth clipping.

{% if accounts.ai_source == 'shared' %}

clip mob came with an AI key from whoever shared it. Add your own only if clips often wait for the AI.

{% elif accounts.ai %}

A key is already saved ({{ accounts.ai }}). Paste a new one only to replace it.

{% endif %}
  1. Open openrouter.ai and sign in. Signing in with Google works.
  2. Open Keys and press Create Key.
  3. Name it clip mob and set the credit limit to 0. That way it can only use free AI and never costs money.
  4. Copy the key and paste it here.

{% elif step == 'youtube' %}

Connect YouTube

A free YouTube key lets clip mob check who owns a video and whether it may be reused.

{% if accounts.youtube %}

A key is already saved ({{ accounts.youtube }}). Paste a new one only to replace it.

{% endif %}
  1. Open Google Cloud, sign in, and create a project called clip mob.
  2. Open the YouTube Data API v3 page and press Enable.
  3. Open Credentials, press Create credentials, then API key.
  4. Copy the key and paste it here. It is free; you will not be charged.
